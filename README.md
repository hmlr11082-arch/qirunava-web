## 🚀 โครงสร้างโปรเจกต์
- `public/`: รวบรวมไฟล์รูปภาพ, ฟอนต์ Noto Sans/Serif Thai, และสไตล์ชีตทั้งหมด
- `src/`: เทมเพลต HTML และสคริปต์การทำงานของระบบหน้าเว็บ
- `dist/`: ไฟล์ HTML/CSS/JS แบบ Static พร้อมสำหรับการนำขึ้น GitHub Pages หรือ Web Server
- `build.js`: สคริปต์คอมไพล์และสร้าง Static Files ทั้งหมด

## 🛠 คำสั่งการบิลด์
```bash
# ทำการ Build เว็บไซต์ลงโฟลเดอร์ dist/
npm run build
```
